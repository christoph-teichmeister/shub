# Checkbox

Native checkbox inside its `<label>`, in the primary accent. Other input attributes (`onchange`, `disabled`, ...) pass through.

| Prop        | Type      | Default | Notes                                      |
| ----------- | --------- | ------- | ------------------------------------------ |
| `label`     | `string`  |         |                                            |
| `checked`   | `boolean` |         | Bindable                                   |
| `hint`      | `string`  |         | Muted second line                          |
| `hideLabel` | `boolean` | `false` | Label for screen readers only (table rows) |

States: unchecked, checked, with hint, disabled.
