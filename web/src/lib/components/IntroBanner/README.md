# IntroBanner

One-line explanation of a view, shown until dismissed. Dismissal is remembered in this browser (`shub.intro.<id>`); blocked storage just shows it again.

| Prop       | Type           | Notes                     |
| ---------- | -------------- | ------------------------- |
| `id`       | `string`       | Per view, e.g. `overview` |
| `children` | snippet (text) | One sentence, plain words |
