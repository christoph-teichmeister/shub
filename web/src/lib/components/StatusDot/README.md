# StatusDot

The small status mark in front of a session name. Decorative (aria-hidden): always put the status text next to it.

| Prop     | Type            | Notes |
| -------- | --------------- | ----- |
| `status` | `SessionStatus` |       |

States: `needs-you` (solid orange dot, the only orange), `working` (cyan ring), `your-turn` (green check), `paused` (pause bars), `exited` (muted ring).
