# Section

A titled block of a settings page (`<section aria-labelledby>` with an `h2`).

| Prop          | Type     | Notes                          |
| ------------- | -------- | ------------------------------ |
| `title`       | `string` |                                |
| `description` | `string` | One muted line under the title |
| `aside`       | snippet  | Right end of the heading row   |
| `children`    | snippet  | Fields, lists, buttons         |

States: title only, with description, with aside.
